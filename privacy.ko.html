Requota 개인정보 처리방침

최종 업데이트: 2026년 9월 20일

Requota는 사용자가 연결한 AI 서비스의 한도를 표시합니다. 당사는 사용자의 계정, 자격 증명, 한도 기록 또는 대화 내용을 수신하는 서버를 운영하지 않습니다. 이 앱에는 광고, 추적 기능 또는 제3자 분석 SDK가 없습니다.

Mac에 저장되는 데이터

계정 이름, 이메일 주소, 서비스 설정, 파일 접근 권한 및 한도 기록은 로컬에 저장됩니다. App Store 버전은 자체 macOS 샌드박스를 사용합니다. 직접 로그인하여 얻은 자격 증명과 사용자가 입력한 API 키는 Requota의 키체인 항목에 저장됩니다. 직접 다운로드 버전은 접근 권한이 제한된 로컬 설정 파일을 사용합니다. 한도 기록은 최대 30일 동안 보관되며 인증 토큰, 프롬프트 또는 응답 텍스트는 포함되지 않습니다. 예열 및 알림 중복 방지 기록은 계정과 함께 보관됩니다.

다른 도구 연결

Requota는 사용자가 선택한 뒤에만 파일이나 폴더를 읽습니다. 로컬 Codex 연결에는 선택한 auth.json을 읽고 그 자격 증명으로 해당 서비스에 한도를 조회합니다. 자격 증명은 계속 Codex가 관리합니다. 접근은 읽기 전용이며, Requota는 Codex 설정을 수정하거나 다른 도구의 키체인 항목을 읽지 않습니다.

프로젝트 사용량 분석을 위해서는 Codex 세션 폴더를 별도로 선택해야 합니다. Requota는 세션 기록을 로컬에서 읽고 시각, 작업 식별자, 작업 폴더, 저장소 그룹 식별자, 모델 이름 및 토큰 수만 추출합니다. 프롬프트나 응답 텍스트를 저장하지 않으며, 이 기록을 업로드하지도 않습니다. 사용량 색인에는 최대 12개월의 관측 기록이 보관됩니다. 파일 위치 정보는 증분 업데이트에 사용되며, 분석을 중지할 때까지 폴더 접근 권한이 유지됩니다.

실시간 모니터링은 같은 세션 폴더 접근 권한으로 파일 변경을 감시하고 토큰 증가량을 계산합니다. CPU, 메모리 및 네트워크 속도는 시스템 API를 사용해 로컬에서 계산합니다. Requota는 네트워크 트래픽의 내용을 읽거나 시스템 지표를 업로드하지 않습니다. 최근 5분의 그래프는 메모리에만 유지됩니다. 샘플링을 일시 중지하거나 워크벤치와 메뉴 막대에 표시할 지표를 선택할 수 있습니다.

응답 성능은 선택 사항인 데이터 원본입니다. 사용자는 내보낸 codex-lb 요청 데이터베이스 또는 store.db가 있는 폴더를 별도로 선택할 수 있습니다. Requota는 성공한 요청의 시각, 모델, 출력 및 추론 토큰 수, 첫 응답까지의 시간, 생성 시간과 대기 시간을 읽습니다. 내부 예열 요청은 제외합니다. 계정 테이블, 키, 프롬프트, 응답 텍스트 및 클라이언트 주소는 읽지 않습니다. 접근 권한은 로컬에 저장됩니다. 최대 30일·100,000건의 요청 기록이 메모리에서 요약되며 업로드되지 않습니다. 응답 성능 메뉴에서 원본 연결을 해제하면 원본 데이터베이스는 변경하지 않고 접근 권한과 캐시를 지웁니다.

서비스 제공자에게 전송되는 데이터

Codex, OpenAI API 또는 Zhipu를 동기화하면 요청은 해당 제공자나 사용자가 설정한 주소로 직접 전송됩니다. 요청에는 인증에 필요한 자격 증명과 매개변수가 포함됩니다. 제공자는 일반적인 네트워크 연결 정보도 받습니다. 데이터 보관과 처리에는 각 제공자의 개인정보 처리방침이 적용됩니다. 직접 로그인은 제공자 웹사이트에서 진행되며 Requota는 사용자의 비밀번호를 받지 않습니다.

제공자는 서비스 제공, 보호 및 개선을 위해 계정 식별자, 요청 시각, 서비스 사용 내역, IP 주소와 진단 기록을 보관할 수 있습니다. OpenAI는 IP 주소에서 대략적인 위치를 추정할 수 있습니다. App Store의 개인정보 보호 레이블은 직접 연결한 제공자의 데이터 처리까지 포괄합니다. 그렇다고 Requota가 로컬 프로젝트 로그, 시스템 지표 또는 대화를 업로드한다는 뜻은 아닙니다. 제공자의 보관 기간은 해당 정책과 사용자 계정 설정에 따라 달라집니다. Requota 연결을 해제해도 제공자가 이미 보유한 데이터는 삭제되지 않습니다.

Codex 계정에서 예열을 켜면 조건이 충족될 때 Requota가 그 계정의 서비스에 짧은 “hello” 메시지를 보냅니다. 이 메시지는 소량의 모델 한도를 사용합니다. 일반 한도 조회는 모델 메시지를 보내지 않습니다. 앞으로의 자동 실행을 중지하려면 예열을 끄세요.

예시 워크벤치

“예시 살펴보기”를 열면 계정을 연결하지 않고 별도의 워크벤치를 볼 수 있습니다. 예시 계정, 한도, 사용량 및 시스템 그래프는 가상 데이터이며 메모리에만 유지됩니다. 예열 시뮬레이션은 메시지를 보내지 않습니다. 예시를 닫으면 그 안에서 바꾼 내용은 삭제됩니다.

구매 및 복원

Pro 영구 구매는 App Store에서 처리합니다. Requota는 StoreKit으로 상품과 시스템에서 검증된 거래를 읽고, 사용 권한을 로컬에서 판단합니다. 당사는 결제 카드 정보나 App Store 비밀번호를 받지 않으며 거래 영수증을 개발자 서버에 업로드하지 않습니다. Apple은 자체 개인정보 처리방침에 따라 구매와 스토어 계정 정보를 처리합니다. “구매 복원”을 선택하면 App Store 계정 확인을 요청받을 수 있습니다. AI 서비스 계정을 제거하거나 사용량 기록을 삭제해도 Pro는 취소되지 않습니다.

사용자 제어

사용자는 모니터링을 일시 중지하고 예열과 알림을 끄거나, 기록을 지우거나, 계정을 제거할 수 있습니다. 계정을 제거하면 Requota가 저장한 해당 계정의 자격 증명, 기록 및 중복 방지 기록이 삭제됩니다. 제공자 서비스에서 로그아웃되거나 제공자 서버의 토큰이 폐기되는 것은 아닙니다. 접근을 완전히 취소하려면 제공자의 계정 설정을 사용하세요.

사용량 분석은 계정 모니터링과 별개입니다. 원본 메뉴에서 분석을 중지하고 로컬 색인과 폴더 접근 권한을 삭제할 수 있습니다. Codex 원본 세션은 삭제되지 않습니다.
