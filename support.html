隐私政策使用帮助

开始使用

在菜单栏点击 AI Monitor，进入“管理账号”并添加连接。首次打开且没有账号时，会自动显示管理窗口。

Codex

优先选择“登录”，在 OpenAI 网页完成设备授权。重新连接时请使用当前账号的邮箱，设置与历史会保留。“API Key”用于 API 费用，不能恢复 ChatGPT 订阅额度。

“本地工具”支持已登录的 Codex。常用凭证位置是 ~/.codex/auth.json；点击“打开常用目录”即可显示隐藏目录，也可按 ⇧⌘G 输入路径。设置过 CODEX_HOME 时请选择对应目录。目录授权会跟随 auth.json 的替换，失效后重新选择即可。

若 Codex 使用钥匙串而没有 auth.json，请使用登录；无需导出钥匙串，也无需安装 Codex。若网页提示设备码登录不可用，请在 ChatGPT 安全设置中启用，工作区账号可能需要管理员开放。

预热、历史与提醒

Codex 预热默认关闭，按账号开启；开启后每个账号独立每分钟扫描额度与重置时间，提前或手动重置也会继续检测。普通检查不消耗模型额度，发送 hello 才消耗少量额度。退出 App 或 Mac 休眠期间暂停，唤醒后补查。趋势图以平滑曲线展示观测，缺测区间用浅色实线连接两端，读数仍为原始观测，不推算 token 数或费用。系统通知需要单独许可。

项目用量

打开侧边栏“用量分析”，选择 ~/.codex 或其中的 sessions 目录。若设置了 CODEX_HOME，请选择对应位置。App 自动增量读取最近 12 个月的本机会话 Token，支持整体汇总、每日热力日历和项目分析。热力图固定展示最近 12 个月，悬停以 K / M / B 查看当天总量及模型分布；没有保存的日志不会补造。仓库信息相同的工作目录会归到同一项目，其余按目录区分；未归属用量保留在总量中。

这些统计不是订阅额度百分比或费用账单，其他设备、云端和缺失记录可能不在其中。来源菜单可重新选择目录，或停止统计并删除本机索引；不会删除 Codex 会话或修改账号。

实时监控

打开侧边栏“实时监控”或按 ⌘3，查看 Token 速率与本机资源。点击项目活动右上角选择全部或指定项目；“显示设置”分别控制工作台与菜单栏中的指标。Token 来源沿用用量分析的 Codex 会话目录授权。

Token / s 是统计窗口内已记录的 Token 增量除以秒数，默认近 30 秒，也可切换 15 或 60 秒。日志可能延迟更新，所以它不等于模型的逐 Token 生成速度。CPU、内存、网络属于整台 Mac，项目筛选只影响 Token；网络曲线显示下载速率，上传速率显示在旁边。

暂停监控会停止快速采样；菜单栏指标全部隐藏且离开实时页面时也暂停采样。系统休眠后重新建立速率基线，缺测时显示未知。曲线仅保留最近五分钟。详情口径可点击页面标题旁的信息按钮。

Pro 买断

商店版的项目用量分析与额度规划属于 Pro。多账号额度查看、重置信息、现有通知、自动预热、整体 Token 总览与热力图、实时监控保持免费。

在“设置 → AI Monitor Pro”查看 App Store 提供的当前价格并购买，一次购买无需订阅。重新安装后，App 会从 StoreKit 读取已有权益；若未显示，可点击“恢复购买”，并使用当时购买的 App Store 账号。价格暂时无法加载不影响已经验证的购买权益；待批准的购买会在完成后自动解锁。

退款与购买撤销由 Apple 处理，App 收到有效更新后恢复免费功能。离线期间可能无法立即得知退款状态；账号、历史与原始文件不会因权益变化被删除。

移除连接

删除账号可同时删除本机记录；若要撤销服务端授权，请在服务商中操作。

故障反馈

同期与响应性能

用量总览可切换 Token 组成 / 模型分布，项目内通过“组成与模型”查看相同明细。“上期同期”比较同一本地日时刻，点开查看模型增减；历史不足、读取不完整时不计算增幅。只统计本机记录，不代表其他设备的账号全量。

额度预测的账号用量条表示已用比例，竖线是本周已过去的时间比例，作为均匀使用的参照。闲置或重置时间无效时不显示这条参照；它不改变账号选择与预热行为。

响应性能支持主动连接 codex-lb 的 SQLite 请求记录（request_logs）。在“实时监控 → 响应性能”选择导出的数据库，或包含 store.db 的目录以一并授权 WAL；不需要将 codex-lb 接为账号来源。缺字段显示未知，输出 TPS 不等于本机 Token 活动速率。成功普通请求纳入分析，失败、取消、删除及内部预热排除。每项指标展示有效样本数和每日中位数，P95 为最近秩分位数；TPS 的 P95 表示高速端，耗时的 P95 表示慢速端。最多读取最近 30 天 / 100,000 条，并显示截断提示。


查看示例

尚未添加账号时，点击“查看示例”；已有账号时从设置底部打开。示例使用独立的虚构数据，不读取私人账号和目录。点击“退出示例”回到原工作台。
