Get started

Click Requota in the menu bar, open “Manage Accounts,” and add a connection. The account window opens automatically when you first launch the app without any accounts.

Codex

Choose “Sign In” to authorize Requota on OpenAI's website using a device code. When reconnecting, use the same account; your settings and history are retained. “API Key” shows API spending and cannot restore ChatGPT subscription quotas.

“Local Tool” can use a Codex sign-in you already have. The usual credential path is ~/.codex/auth.json. “Open Default Folder” reveals this hidden location; you can also press ⇧⌘G and enter a path. If you set CODEX_HOME, choose that folder instead. Folder permission follows replacement of auth.json; select the folder again if permission expires.

If Codex stores credentials in Keychain and has no auth.json, use “Sign In” instead. You do not need to export Keychain items or install Codex. If the website says device-code sign-in is unavailable, enable it in ChatGPT security settings. A workspace administrator may need to allow it.

Warm-up, history, and reminders

Codex warm-up is off by default and can be enabled for each account. Requota checks each enabled account's quota and reset time every minute, including after early or manual resets. Ordinary checks do not consume model quota; sending “hello” does. Checks pause while the app is closed or the Mac sleeps and resume after wake. The trend chart smoothly connects observations; a lighter line bridges missing samples, but displayed readings remain the original observations. It does not infer token counts or costs. System notifications require separate permission.

Project usage

Open “Usage Analysis” in the sidebar and choose ~/.codex or its sessions folder. If CODEX_HOME is set, choose that location. Requota incrementally reads up to 12 months of local Codex session tokens and shows totals, a daily heatmap, and project analysis. The heatmap always shows the latest 12 months. Hover over a day to see its total and model breakdown in K, M, or B units. Missing logs are not invented. Working folders with the same repository identity are grouped as one project; others are grouped by folder. Unattributed usage remains in the total.

These figures are not subscription quota percentages or a bill. Other devices, cloud sessions, and missing logs may be absent. Use the source menu to choose a different folder or stop analysis and delete the local index. Neither action deletes Codex sessions or changes accounts.

Real-time monitoring

Open “Real-Time Monitoring” in the sidebar or press ⌘3 to see token rates and Mac resources. The project-activity menu lets you choose all or selected projects. “Display Settings” controls workbench and menu-bar metrics separately. Token rates use the Codex sessions folder selected for usage analysis.

Token/s is the recorded token increase divided by the selected window length: 30 seconds by default, or 15 or 60 seconds. Logs can arrive late, so this is observed throughput, not precise per-token generation speed. CPU, memory, and network represent the whole Mac; project filtering affects only tokens. The network chart shows downloads, with upload speed alongside it.

Pausing monitoring stops rapid sampling. Sampling also stops when every menu-bar metric is hidden and you leave the real-time page. After sleep, Requota starts a new rate baseline; missing data appears as unknown. Charts retain only the last five minutes. Use the information button beside the page title for the calculation details.

Pro lifetime purchase

In the App Store version, project usage analysis and quota planning require Pro. Multi-account quota viewing, reset information, existing notifications, automatic warm-up, overall token totals and heatmap, and real-time monitoring remain free.

“Settings → Requota Pro” shows the current App Store price. Pro is a one-time purchase without a subscription. After reinstalling, Requota reads your existing entitlement from StoreKit. If Pro does not appear, choose “Restore Purchases” with the App Store account used to buy it. A temporary price-loading problem does not remove a verified entitlement. Purchases awaiting approval unlock automatically after approval.

Apple handles refunds and purchase revocations. Requota returns to free features after receiving a verified transaction update. An offline app may not learn about a refund immediately. Changes to Pro access do not delete accounts, history, or original files.

Remove a connection

Removing an account can also delete its local history. To revoke server-side access, use the provider's account controls.

Period comparisons and response performance

Usage Overview switches between token breakdown and model distribution. A project's “Breakdown & Models” shows the same details. “Same Time in Previous Period” compares equivalent local times and can show changes by model. Insufficient or incomplete history prevents percentage comparisons. Only readable local records are counted, not full account usage across other devices.

In quota planning, an account's bar shows the percentage used. Its vertical marker shows how much of the week has passed as an even-use reference. The marker is hidden when the account is idle or the reset time is invalid. It does not alter account selection or warm-up.

Response performance reads an optional codex-lb SQLite request_logs database. In “Real-Time Monitoring → Response Performance,” choose an exported database or a folder containing store.db to grant access to its WAL file. You do not need to add codex-lb as an account source. Missing fields remain unknown. Output TPS is separate from local token activity. Only successful ordinary requests are counted; failures, cancellations, deleted requests, and internal warm-ups are excluded. Each metric shows its valid sample count and daily median. P95 uses nearest-rank calculation: for TPS it reflects faster requests, and for durations it reflects slower ones. At most 30 days or 100,000 records are read; Requota indicates when data is truncated.

View a sample

Choose “View Sample” when no accounts are connected, or from the bottom of Settings if you already have accounts. Synthetic data is kept separately and never reads private accounts or folders. “Exit Sample” returns to your original workbench.
