개인정보 처리방침도움말

시작하기

메뉴 막대에서 Requota를 클릭해 메인 창을 연 다음 계정 메뉴에서 “계정 추가…”를 선택하세요. 계정이 없는 상태에서 앱을 처음 실행하면 계정 창이 자동으로 열립니다.

Codex

“로그인”을 선택하면 기기 코드로 OpenAI 웹사이트에서 Requota를 승인할 수 있습니다. 다시 연결할 때는 같은 계정을 사용하세요. 설정과 기록이 유지됩니다. “API 키” 방식은 API 지출을 표시하며 ChatGPT 구독 한도를 복원할 수 없습니다.

“로컬 도구”는 기존 Codex 로그인을 사용할 수 있습니다. 자격 증명의 일반적인 경로는 ~/.codex/auth.json입니다. “추천 폴더 열기…”로 이 숨김 위치를 표시하거나 ⇧⌘G를 눌러 경로를 입력하세요. CODEX_HOME을 설정했다면 그 폴더를 선택하세요. 폴더 접근 권한은 auth.json 파일이 교체되어도 유지됩니다. 권한이 만료되면 폴더를 다시 선택하세요.

Codex가 자격 증명을 키체인에 저장하여 auth.json이 없다면 “로그인” 방식을 사용하세요. 키체인 항목을 내보내거나 Codex를 설치할 필요는 없습니다. 웹사이트에서 기기 코드 로그인을 사용할 수 없다고 표시되면 ChatGPT 보안 설정에서 이 기능을 켜세요. 워크스페이스 관리자의 허용이 필요할 수도 있습니다.

예열, 기록 및 알림

Codex 예열은 기본적으로 꺼져 있으며 계정별로 켤 수 있습니다. Requota는 예열이 켜진 계정의 한도와 재설정 시각을 1분마다 확인하며, 조기 재설정이나 수동 재설정 후에도 확인합니다. 일반 조회는 모델 한도를 사용하지 않지만 “hello” 전송은 사용합니다. 앱을 닫거나 Mac이 잠자기 상태이면 조회가 멈추고, 깨어나면 재개됩니다. 추이 그래프는 관측값을 부드럽게 연결합니다. 빠진 샘플을 잇는 선은 더 연하게 표시하지만 읽기 값은 원래 관측값을 유지합니다. 토큰 수나 비용을 추정하지 않습니다. 시스템 알림에는 별도 권한이 필요합니다.

프로젝트 사용량

사이드바에서 “사용량 분석”을 열고 ~/.codex 또는 그 안의 sessions 폴더를 선택하세요. CODEX_HOME을 설정했다면 그 위치를 선택하세요. Requota는 최대 12개월의 로컬 Codex 세션 토큰을 증분 방식으로 읽고 총량, 일일 히트맵 및 프로젝트 분석을 표시합니다. 히트맵에는 항상 최근 12개월이 표시됩니다. 날짜에 마우스를 올리면 그날의 총량과 모델별 사용량을 K, M, B 단위로 볼 수 있습니다. 없는 로그의 사용량을 만들어 넣지 않습니다. 저장소 식별자가 같은 작업 폴더는 하나의 프로젝트로 묶고, 그 외에는 폴더별로 묶습니다. 출처를 확인할 수 없는 사용량도 총량에는 포함됩니다.

이 수치는 구독 한도 비율이나 청구서가 아닙니다. 다른 기기, 클라우드 세션 및 누락된 로그는 포함되지 않을 수 있습니다. 원본 메뉴에서 다른 폴더를 선택하거나 분석을 중지하고 로컬 색인을 삭제할 수 있습니다. 어느 작업도 Codex 세션을 삭제하거나 계정을 변경하지 않습니다.

실시간 모니터링

사이드바에서 “실시간 모니터링”을 열거나 ⌘3을 눌러 토큰 속도와 Mac 리소스를 확인하세요. 프로젝트 활동 메뉴에서 모든 프로젝트 또는 선택한 프로젝트를 볼 수 있습니다. “표시 설정”에서는 워크벤치와 메뉴 막대의 지표를 별도로 설정합니다. 토큰 속도는 사용량 분석에 선택한 Codex 세션 폴더를 사용합니다.

토큰/초는 기록된 토큰 증가량을 선택한 기간으로 나눈 값입니다. 기본 기간은 30초이며 15초 또는 60초도 선택할 수 있습니다. 로그가 늦게 도착할 수 있으므로 관측된 처리량이며 토큰별 생성 속도를 정확히 나타내지 않습니다. CPU, 메모리 및 네트워크는 Mac 전체의 수치입니다. 프로젝트 필터는 토큰에만 적용됩니다. 네트워크 그래프에는 다운로드가 표시되고 옆에 업로드 속도가 함께 표시됩니다.

모니터링을 일시 중지하면 빠른 샘플링이 멈춥니다. 메뉴 막대의 모든 지표를 숨기고 실시간 페이지를 벗어나도 샘플링이 멈춥니다. 잠자기에서 깨어나면 Requota는 속도 기준점을 새로 만들고 누락된 데이터는 알 수 없음으로 표시합니다. 그래프에는 최근 5분만 보관됩니다. 계산 방법은 페이지 제목 옆의 정보 버튼에서 확인하세요.

Pro 영구 구매

App Store 버전에서 프로젝트별 사용량 분석과 한도 계획을 사용하려면 Pro가 필요합니다. 여러 계정의 한도 보기, 재설정 정보, 기존 알림, 자동 예열, 전체 토큰 합계와 히트맵, 실시간 모니터링은 무료로 계속 제공됩니다.

“설정 → Requota Pro”에서 현재 App Store 가격을 확인할 수 있습니다. Pro는 구독이 아닌 일회성 구매입니다. 앱을 다시 설치해도 Requota는 StoreKit에서 기존 사용 권한을 읽습니다. Pro가 표시되지 않으면 구매할 때 사용한 App Store 계정으로 “구매 복원”을 선택하세요. 일시적인 가격 로딩 문제로 이미 검증된 사용 권한이 사라지지는 않습니다. 승인 대기 중인 구매는 승인 후 자동으로 잠금 해제됩니다.

환불과 구매 취소는 Apple에서 처리합니다. Requota는 검증된 거래 업데이트를 받은 뒤 무료 기능 상태로 돌아갑니다. 오프라인 상태에서는 환불 사실이 즉시 반영되지 않을 수 있습니다. Pro 사용 권한이 바뀌어도 계정, 기록 또는 원본 파일은 삭제되지 않습니다.

연결 제거

계정을 제거하면 해당 계정의 로컬 기록도 삭제될 수 있습니다. 서버 측 접근 권한을 취소하려면 제공자의 계정 설정을 사용하세요.

기간 비교 및 응답 성능

사용량 개요에서 토큰 구성과 모델 분포를 전환할 수 있습니다. 프로젝트의 “구성 및 모델”에도 같은 정보가 표시됩니다. “이전 기간의 같은 시각”은 해당하는 현지 시각끼리 비교하며 모델별 변화를 표시할 수 있습니다. 기록이 부족하거나 불완전하면 비율 비교를 할 수 없습니다. 다른 기기를 포함한 계정 전체 사용량이 아니라 읽을 수 있는 로컬 기록만 집계합니다.

한도 계획에서 계정의 막대는 사용된 비율을 나타냅니다. 세로 표시는 주간 기간이 얼마나 지났는지를 균등 사용의 기준으로 보여 줍니다. 계정이 유휴 상태이거나 재설정 시각이 유효하지 않으면 표시하지 않습니다. 이 표시는 계정 선택이나 예열을 바꾸지 않습니다.

응답 성능은 선택 사항인 codex-lb SQLite request_logs 데이터베이스를 읽습니다. “실시간 모니터링 → 응답 성능”에서 내보낸 데이터베이스 또는 store.db가 있는 폴더를 선택하면 WAL 파일에도 접근할 수 있습니다. codex-lb를 계정 원본으로 추가할 필요는 없습니다. 누락된 필드는 알 수 없음으로 남깁니다. 출력 TPS는 로컬 토큰 활동과 별개의 수치입니다. 성공한 일반 요청만 집계하며 실패, 취소, 삭제된 요청과 내부 예열은 제외합니다. 각 지표에는 유효한 샘플 수와 일일 중앙값이 표시됩니다. P95는 최근접 순위법으로 계산합니다. TPS에서는 더 빠른 요청을, 소요 시간에서는 더 느린 요청을 나타냅니다. 최대 30일 또는 100,000건의 기록을 읽으며 데이터가 잘렸다면 Requota가 알려 줍니다.

예시 보기

계정을 연결하지 않았다면 “예시 살펴보기”를 선택하세요. 계정이 이미 있다면 설정 아래쪽에서도 열 수 있습니다. 가상 데이터는 별도로 보관되며 실제 계정이나 비공개 폴더를 읽지 않습니다. “예시 종료”를 선택하면 원래 워크벤치로 돌아갑니다.
