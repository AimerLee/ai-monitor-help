隱私權政策使用說明

開始使用

點選選單列中的 Requota，進入「管理帳號」並新增連線。首次開啟且尚無帳號時，管理視窗會自動顯示。

Codex

建議先選擇「登入」，到 OpenAI 網頁完成裝置授權。重新連線時，請使用目前帳號的電子郵件地址；原有設定與歷史記錄會保留。「API Key」用於 API 費用查詢，無法恢復 ChatGPT 訂閱額度。

「本機工具」支援已登入的 Codex。憑證通常位於 ~/.codex/auth.json；點選「開啟常用目錄」即可顯示隱藏目錄，也可按 ⇧⌘G 輸入路徑。若設定過 CODEX_HOME，請選取對應目錄。目錄授權會跟隨 auth.json 的替換；授權失效時，重新選取即可。

若 Codex 使用鑰匙圈而沒有 auth.json，請改用登入；無須匯出鑰匙圈，也無須安裝 Codex。若網頁顯示裝置代碼登入不可用，請到 ChatGPT 安全性設定中啟用；工作區帳號可能需要管理員開放這項功能。

預熱、歷史記錄與提醒

Codex 預熱預設關閉，可逐一為帳號開啟。開啟後，每個帳號會獨立地每分鐘檢查額度與重設時間；提前或手動重設也會繼續偵測。一般檢查不消耗模型額度，只有傳送 hello 才會消耗少量額度。結束 App 或 Mac 進入睡眠時會暫停，喚醒後再補查。趨勢圖以平滑曲線呈現觀測值；缺測區間以淺色實線連接兩端，讀數仍是原始觀測值，不會推算 Token 數量或費用。系統通知需要另外取得授權。

專案用量

開啟側邊欄中的「用量分析」，選取 ~/.codex 或其下的 sessions 目錄。若設定了 CODEX_HOME，請選取對應位置。App 會自動增量讀取最近 12 個月儲存在本機的工作階段 Token 記錄，提供整體彙總、每日熱度日曆及專案分析。熱度圖固定顯示最近 12 個月；將滑鼠停留在格子上，可用 K / M / B 單位檢視當天總量與模型分布。未儲存的日誌不會憑空補上。儲存庫資訊相同的工作目錄會歸入同一專案，其餘則依目錄區分；未歸屬的用量仍計入總量。

這些統計不是訂閱額度百分比或費用帳單，其他裝置、雲端及缺失的記錄可能不在其中。您可從來源選單重新選取目錄，或停止統計並刪除本機索引；這不會刪除 Codex 工作階段或修改帳號。

即時監控

開啟側邊欄中的「即時監控」或按 ⌘3，檢視 Token 速率與本機資源。點選專案活動右上角，可選擇全部或指定專案；「顯示設定」分別控制工作台及選單列中的指標。Token 資料沿用用量分析對 Codex 工作階段目錄的授權。

Token / s 是統計視窗內已記錄的 Token 增量除以秒數，預設採用最近 30 秒，也可改為 15 或 60 秒。日誌可能延後更新，因此這項數值不等於模型逐一產生 Token 的速度。CPU、記憶體和網路指標涵蓋整台 Mac，專案篩選只影響 Token；網路曲線顯示下載速率，上傳速率顯示在旁邊。

暫停監控會停止快速取樣；選單列指標全部隱藏且離開即時監控頁面時，也會暫停取樣。系統從睡眠中喚醒後會重建速率基準，缺測時顯示未知。曲線只保留最近五分鐘。點選頁面標題旁的資訊按鈕，可查看詳細計算方式。

Pro 一次買斷

App Store 版本的專案用量分析與額度規劃屬於 Pro 功能。多帳號額度檢視、重設資訊、現有通知、自動預熱、整體 Token 總覽與熱度圖，以及即時監控仍可免費使用。

在「設定 → Requota Pro」查看 App Store 提供的目前價格並購買；一次購買，無須訂閱。重新安裝後，App 會從 StoreKit 讀取既有權益；若未顯示，請點選「恢復購買」，並使用原本購買時的 App Store 帳號。價格暫時無法載入，不影響已驗證的購買權益；等待核准的購買會在完成後自動解鎖。

退款及購買撤銷由 Apple 處理。App 收到有效更新後，會恢復免費功能。離線時可能無法立即得知退款狀態；帳號、歷史記錄及原始檔案不會因權益變更而遭刪除。

移除連線

刪除帳號時，可以同時刪除本機記錄；若要撤銷伺服器端的授權，請到服務供應商處操作。

問題回報

同期比較與回應效能

您可以在用量總覽切換 Token 組成／模型分布，或在專案內透過「組成與模型」檢視相同明細。「上個期間的同期」會比較相同的本機日期與時間，點開可查看各模型的增減；歷史記錄不足或讀取不完整時，不會計算增幅。統計只涵蓋本機記錄，不代表其他裝置上的帳號總用量。

額度預測中的帳號用量條表示已用比例，豎線表示本週已經過的時間比例，供您參照平均使用速度。帳號閒置或重設時間無效時，不會顯示這項參照；它不會改變帳號選擇或預熱行為。

回應效能支援主動連線 codex-lb 的 SQLite 請求記錄（request_logs）。從「即時監控 → 回應效能」選取匯出的資料庫，或包含 store.db 的目錄，便能一併授權讀取 WAL；無須將 codex-lb 設為帳號來源。缺少欄位時顯示未知，輸出 TPS 不等於本機 Token 活動速率。分析只納入成功的一般請求，排除失敗、取消、刪除及內部預熱。每項指標都會顯示有效樣本數和每日中位數；P95 使用最近秩百分位數，TPS 的 P95 表示高速端，耗時的 P95 表示慢速端。最多讀取最近 30 天或 100,000 筆記錄，達上限時會顯示截斷提示。

檢視範例

尚未新增帳號時，點選「檢視範例」；已有帳號時，可從設定頁底部開啟。範例使用獨立的虛構資料，不會讀取私人帳號或目錄。點選「離開範例」即可返回原工作台。
